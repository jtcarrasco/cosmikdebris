# Cosmik Debris

Personal blog about maker projects, Linux adventures, hardware hacks, and experimental tech
musings — homelab builds, 3D printing, self-hosting, and whatever breaks and gets fixed along
the way. Built with Jekyll and the Chirpy theme.

## Stack

- **Jekyll** — static site generator
- **jekyll-theme-chirpy** — theme
- Deployed via GitHub Pages

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Dev server config includes a Tailscale-bound host/port for local network access during
development.

## Content

Posts live in `_posts/`. Draft/tutorial source files are managed separately before publishing.
